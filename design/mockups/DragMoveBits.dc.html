Behaviour
TargetsFolder rows, folder cards and the breadcrumbs. Not files, not the empty area, not the sidebar.
RefusedA folder onto itself, into its own subfolder, or anything onto the folder it already sits in. No ring appears and the drop does nothing.
SelectionDragging a selected row takes the whole selection; dragging an unselected row takes just that one.
CollisionMOVE never overwrites. The items that fit are moved, the rest are named in one toast.
UndoEvery move gets the same Undo toast that Trash already uses, for 6 seconds.
UploadsDropping files from Finder or Explorer still uploads; that path is untouched.
macOS filesA native file drag can only go one way, so a file keeps going out to Finder. Move it with ⌘X ⌘V or “Move to…”.
Windows outToday’s Windows drag-out never lands anything. It becomes an internal move, and the toast points at what works.
